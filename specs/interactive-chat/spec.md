## 背景

MyCode 是使用 Python 开发的终端 AI 编程助手，长期方向类似 Claude Code。当前项目只有项目指引，没有实现代码。本轮从零实现纯对话能力，为后续 Agent 功能提供基础。

需求澄清时比较了两种交互形态：终端滚动式交互实现较轻，适合基础对话；全屏 TUI 提供固定输入区和可滚动对话区，但需要处理布局和终端尺寸变化。用户选择全屏 TUI。

## 目标

- 用户以 `MyCode` 启动应用，进入全屏 TUI，使用固定输入区和可滚动对话区进行交互。
- 支持提问、SSE 流式回复和多轮对话；记忆仅保留在当前运行会话中，退出后不保存。
- 支持 Anthropic Claude 与 OpenAI 两种协议，通过统一 Provider 接口使用模型，便于后续扩展。
- YAML 管理多个供应商，每项保持指定的六个字段；启动时按 name 选择，默认使用第一项。
- 本轮仅做纯对话，不加入工具调用、文件操作或代码编辑等 Agent 能力。

## 功能需求

- **F1 全屏交互**：固定输入区、可滚动对话区；Enter 发送，Alt+Enter 换行；空白输入不发送。生成期间禁止重复提交。
- **F2 供应商配置**：YAML 顶层为供应商列表；每项包含必填的 `name`、`protocol`、`model`、`base_url`、`api_key`，以及可选的 `thinking`，默认关闭。name 唯一；`protocol` 使用 `anthropic` 或 `openai`。
- **F3 启动选择**：支持 `MyCode --config <路径> --provider <name>`；默认读取当前目录的 `mycode.yaml`，未指定 provider 时使用第一项。配置无效时给出明确错误。
- **F4 流式回复**：两个后端均通过 SSE 接收增量内容，收到后立即显示。按流中的文本增量更新，不额外用延时模拟逐字输出。
- **F5 多轮记忆**：后续请求携带当前会话的历史消息；仅完整成功的问答进入历史，失败或取消的问答不进入后续上下文。
- **F6 扩展思考**：Anthropic 配置 `thinking: true` 时启用 extended thinking；思考内容独立流式显示，结束后可折叠。OpenAI 本轮不支持此选项，设为 true 时明确报错。
- **F7 中断与退出**：生成时 Ctrl+C 取消本次请求并保留已显示内容，允许继续提问；空闲时 Ctrl+C 退出，Ctrl+D 随时退出。
- **F8 错误恢复**：认证失败、网络异常或流中断时显示错误，恢复输入能力；不自动重试，避免重复请求。

## 非功能需求

- **N1 扩展性**：TUI 和会话管理通过统一 Provider 接口使用模型；新增后端不需要修改对话主流程。
- **N2 响应性**：请求和流式接收期间，界面仍可滚动、取消和退出；终端调整尺寸后布局保持可用。
- **N3 显示完整性**：正确显示中文及跨流片段的文本，不丢字、不重复；思考内容与正式回复明确区分。
- **N4 密钥保护**：界面、日志及错误信息不泄露 API key；示例配置仅使用占位值。
- **N5 运行环境**：第一版支持 Python 3.11 及以上，面向 macOS、Linux 交互终端；暂不验收 Windows。
- **N6 可验证性**：覆盖配置校验、两种协议的流式处理、会话记忆、取消和错误恢复；最终在 tmux 中执行真实 API 对话验收。缺少凭据或环境时如实报告未验收项。

## 不做的事

- 工具调用、文件读写、代码编辑、命令执行等 Agent 能力。启动所需的配置文件读取不受此限制。
- 对话持久化、历史会话恢复、跨会话记忆及上下文自动压缩。
- 运行中切换供应商或模型；需要退出后重新启动。
- OpenAI 的推理模式、思考内容展示，以及图片、音频等多模态输入。
- Markdown 富文本渲染、语法高亮；第一版以纯文本显示内容。
- 自动重试、多个请求并发生成、Token 用量和费用统计。
- Windows 兼容性验收。

## 验收标准

- **AC1 → F1**：启动后进入全屏 TUI；对话可滚动、输入区固定；Enter 发送、Alt+Enter 换行，空白输入和生成期间重复提交不会发起请求。
- **AC2 → F2、F3**：配置两个供应商，验证默认选择第一项、按 name 选择及指定配置路径；缺失必填字段、重复 name、未知协议或供应商时给出明确错误。
- **AC3 → F4、N3**：两个后端都能在响应结束前显示多次文本增量；中文跨片段传输时不丢字、不重复。
- **AC4 → F5**：先告知一个临时口令，再询问口令，模型能够根据历史回答；重启后请求不携带上次会话历史。
- **AC5 → F5、F7、F8**：请求失败或被取消后，其问答不进入后续请求上下文；此前成功的历史仍保留。
- **AC6 → F6**：Claude 开启 thinking 后，思考内容在独立区域实时显示，完成后可折叠，正式回复单独显示；关闭时不发送启用参数。OpenAI 配置 thinking 为 true 时明确报错。
- **AC7 → F7**：生成时 Ctrl+C 取消请求并保留已显示内容，可继续提问；空闲时 Ctrl+C 退出，Ctrl+D 随时退出。
- **AC8 → F8、N4**：模拟认证失败、网络异常和流中断，界面显示错误并恢复输入，不自动重试，错误信息不泄露密钥。
- **AC9 → N1、N2**：验证两个后端使用统一接口；生成期间可滚动、取消，调整终端尺寸后布局仍可用。
- **AC10 → N5、N6**：在 tmux 中启动 MyCode，对两个真实 API 后端分别执行流式、多轮对话验收，并验证 Claude thinking；记录实际结果，缺少凭据的项目标记为未验收。
